# Quick Fix for Android Studio Gradle Error

## ✅ SOLUTION (Takes 2 minutes)

### In Android Studio:

1. **File** → **Settings** (Ctrl+Alt+S)

2. Go to: **Build, Execution, Deployment** → **Build Tools** → **Gradle**

3. Set **"Gradle user home"** to:
   ```
   C:\Users\Akram\.gradle
   ```

4. Under **"Use Gradle from"**, select:
   ```
   'gradle-wrapper.properties' file
   ```

5. Click **Apply** → **OK**

6. **File** → **Invalidate Caches** → **Invalidate and Restart**

7. After restart: **File** → **Sync Project with Gradle Files**

---

## ✅ Done!

The error should be gone. Android Studio will now use your user directory instead of trying to write to Program Files.
